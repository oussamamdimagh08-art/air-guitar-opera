# Air Guitar Opera Edition

Created and presented by Oussama Mdemagh.

A 90-second calm virtual-guitar experience for a volunteer with no musical experience. The original music continues automatically; hand movements only add graceful nylon-guitar accents and visual effects.

## Audio design
- Original slow progression at 76 BPM
- Warm major-seven and minor-seven harmony
- Karplus-Strong-inspired plucked nylon-string synthesis
- Soft sine body resonance
- Concert-hall reverb and subtle delay
- No aggressive distortion or rock sound
- Automatic applause and final score

## Launch
Open with VS Code Live Server, allow camera access, use full screen, and connect the computer to good speakers for the best result.
